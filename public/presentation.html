PTV Journey Planner

Real-time public transport journey planning for Melbourne, powered by Google and PTV APIs.

What it does

1

Search any destination

Type any Melbourne address or stop — autocomplete finds it instantly via Google Places.

2

Plan your journey

Google Routes finds the best transit path, breaking it into legs — train, tram, or bus.

3

Real-time departures

Each leg shows the next 5 departures from PTV, with route number and minutes until departure.

4

Live alerts

Delays and disruptions are shown per leg, so you know before you leave.

APIs Used

Places Autocomplete

Suggests Melbourne stops and addresses as the user types.

Google

Routes API v2

Computes the optimal transit journey with walking legs.

Google

Maps JavaScript API

Renders the route on an interactive map with stop markers.

PTV

PTV Timetable API v3

Provides real-time departure times for each leg (HMAC-SHA1 signed).

Alerts

Alerts API

Returns delay minutes and disruption alerts per route.
